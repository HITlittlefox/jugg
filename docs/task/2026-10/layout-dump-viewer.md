# Layout dump 本地检查工具

## 已确认的目标与范围

2026-10-16 用户确认方案并授权实现：用单个本地 HTML 打开 `ui` 或 `interaction` JSON，以二维线框帮助人工检查导出内容。重叠通过候选列表和节点树选择；首版不加入 3D、自动差异匹配或截图叠加。

- 新增 `tools/layout-dump-viewer.html`：原生 HTML/CSS/JavaScript + SVG，无网络依赖、后端或构建步骤；支持文件选择、拖入、粘贴、多窗口切换、缩放平移、搜索、节点树/属性/画布联动、重叠候选、聚焦子树、隐藏与恢复。
- 更新 `tools/README.md`：使用入口、操作和数据解释边界。
- 本文件记录实现与验证；在现有 `08_mcp_layout_verify_design.md` 补充离线检查入口，保持知识库同步。
- 不修改插件采集、转换、MCP/CLI 契约。该工具服务 dump 数据 review；现有 Wiki 的插件操作说明与支持范围未改变，不需要同步 Wiki。

## 数据与交互约束

- 原样解释 `windows[].root/children`，坐标使用声明的 `units.bounds`，不再次按 density 换算。interaction 的树是输出树，不能推断真实父子关系或绘制顺序。
- `jugg_details` 是省略提示，不是控件、不参与控件统计；不能从文件恢复已省略内容。
- 保留窗口边界；默认聚焦窗口范围，允许显示窗口外内容。子树或无有效窗口范围时明确标记范围限制。
- 隐藏/透明节点及其后代默认不绘制，但始终能在树中检查，开关可虚线显示；临时隐藏仅作用于当前查看状态。
- 无效/缺失/零面积 bounds 不画矩形，节点和诊断仍保留。几何相交不能证明实际可见、裁剪或遮挡顺序。
- 全局 warnings、节点 message、truncated 和未知单位不能被成功导入提示掩盖。导入失败保留已打开的有效文件。
- 候选列表按输出树深度与顺序帮助选择，并明确不是 Z 轴顺序；支持悬停预览和点击固定选择。

## 视觉与结构

采用密度适中的检查器：左侧节点树、中间线框、右侧属性；窄屏将属性移至下方。正文使用系统中文无衬线字体，坐标与原始 JSON 使用系统等宽字体。颜色：工作区 `#f1f4f7`、面板 `#ffffff`、正文 `#243447`、边线 `#d7e0e8`、选中 `#2463c5`、警告 `#946200`。边线编码布局、蓝色编码选中；不使用装饰动画或外部字体。

## 失败证据与验证策略

- 实现前 `tools/layout-dump-viewer.html` 不存在，现有工具无法直接将提供的 JSON 展示为可选节点的布局框架。
- 行为 owner 为独立 HTML 页面，稳定契约为导入、几何显示、节点选择和诊断保留。仓库没有该工具的浏览器测试设施；不引入构建/测试依赖、不为 Kotlin/JVM 增加与页面责任不符的测试。
- 先准备临时浏览器验收脚本，确认缺失页面不能满足入口断言；随后通过真实浏览器与 DOM/SVG 可观察结果进行定向自动验收，辅以截图检查。脚本与私有 dump 不提交仓库。
- 覆盖用户提供的 18 份 JSON；检查首页 ui 的 745 节点、优化后 interaction 的 272 节点和 20 个省略提示。
- 合成输入覆盖多窗口、重复 id、未知/缺失单位、子树、屏幕外、隐藏祖先、缺失/零面积 bounds、诊断与截断、恶意文本、非法 JSON；检查搜索、重复点击候选、键盘、缩放平移、聚焦、隐藏恢复及窄屏布局。
- 完成后执行 `git diff --check`，并按 feature-development 技能委派只读实现审查；只提交本次变更，不推送或创建 PR。

## 实现与验证结果

- 实现与确认范围一致。节点使用窗口内的遍历位置区分，重复资源 id 不会合并；虚拟 id 优先显示可读类名。真实原始节点 JSON 可展开检查，不改写 children 内容。
- 使用本机 Chrome + 工作区已有 Playwright 运行临时验收脚本（`/tmp/jugg-layout-viewer-review/smoke.cjs`、`verify.cjs`），不引入仓库依赖或测试专用生产接口。实现前同一入口失败于 `net::ERR_FILE_NOT_FOUND`，实现后通过。
- 18 份真实文件导入均成功，节点与省略计数和源文件一致，dp 未重复换算；首页 ui 745 节点、after interaction 272 节点 / 20 处省略均匹配。
- 合成浏览器验收覆盖重叠候选与重复 id、树/属性/选中框联动、搜索、子树聚焦、分支隐藏/恢复、继承可见性、屏幕外定位、多窗口、原始 JSON、缺失/零面积 bounds、截断与诊断、文本转义、非法导入保留旧视图、未知单位与 px、拖入/粘贴、按钮/滚轮/键盘缩放和平移。
- 已检查桌面 ui / interaction 与 390px 窄屏截图；窄屏无横向溢出，浏览器未捕获页面脚本异常。仅零面积等信息默认收起，真正的采集警告、截断与无效几何默认展开；改变查看区尺寸会重新适应布局。
- 该工具不涉及插件编译、部署或采集实现，没有运行 Gradle；使用真实浏览器验证最终交互边界。
- 独立只读审查发现并复现两项边界问题：子树根误当窗口视口，以及聚焦子树后搜索泄露范围外祖先。均已补失败断言并修正：`rootLayout` / `windowType=subtree` 各自独立禁止根裁剪，搜索及上下文节点始终限制在聚焦范围内。
- 修正后 18 份样本与合成行为回归、入口 smoke 均通过；`git diff --check` 通过。独立定向复核确认两项问题关闭，并分别验证子树根外保留、普通窗口裁剪不变、聚焦搜索与选中定位联动；未发现衍生问题。
- 当前验证使用 macOS 本机 Chrome；未声称覆盖其他浏览器，也未验证真实 Android 画面还原。工具本身只检查已有 JSON，不连接设备。
